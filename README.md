This repository contains the simulations I created for my reconfigurable-wheel stairclimber research project. The simulations are coded in Python and use PyBullet, the Python module of the Bullet Physics Engine.  
In these simulations, I compare four different designs in their ability to ascend and descend stairs successfully. The four designs being compared are an ideal straight-spoke design, an ideal curved-spoke design, a "practical" curved-spoke design, and my new stairclimber design.
All four wheel designs are attached to a 0.8m x 0.3m x 0.03m base.  
Stairclimber_Ascent.py compares the ascent capabilities of each of the four designs. The code conducts a parameter sweep for each of friction, step height, step depth, and driving torque. A successful ascent is one that takes less than 5000 frames, or about 20.8 seconds in real-world time. Each design is tested against a parameter until it fails to ascend successfully, after which the final value is recorded as the limiting point.  
Stairclimber_Descent.py compares the descent capabilities of each of the four designs. The code conducts a parameter sweep for friction and step depth. A successful descent is one that takes more than 1500 frames, or about 6.25 seconds in real-world time. Each design is tested against a parameter until it fails to descend successfully, after which the final value is recorded as the limiting point. The criteria for successful descent was chosen because if the robot descends too quickly, it may be damaged in the process. To maintain fairness, the target angular velocity of each wheel is set to 3 rad/s during descent.  

To run the simulation, download the main program (Stairclimber_Ascent.py or Stairclimber_Descent.py). Then, download all URDF files and all CAD files, changing the filepaths in the URDF as appropriate. Finally, change the URDF filepaths in the main program and run the simulation.
